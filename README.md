# Schelden Bank

### Modern banking, thoughtfully designed.

Schelden Bank is a premium, full-stack **simulated banking platform** designed to demonstrate how a modern digital banking experience can work from both the customer and bank-operations perspectives.

The platform includes a complete customer banking experience, secure administrative operations, transaction management, card controls, financial services, realtime support, analytics, notifications, documents, security controls, and audit trails.

> **Important:** Schelden Bank is a software simulation and portfolio/project experience. It is not a real financial institution and does not process real money.

---

## ✨ Overview

Schelden Bank was built around one idea:

> **Give customers a modern banking experience while giving the bank complete, secure operational control behind the scenes.**

The system is divided into two major experiences:

### Customer Banking

Customers can:

- Create and verify an account
- Complete their profile
- View their banking dashboard
- View accounts and balances
- View Belgian IBANs
- Browse and search transactions
- Request accounts
- Request cards
- Manage eligible card settings
- Manage beneficiaries
- Explore savings
- Explore investments
- Use the loan simulator
- View documents
- Receive notifications
- Manage security and preferences
- Contact Live Support
- Upload avatars and support attachments
- View financial insights and analytics

### Bank Administration

Authorized bank administrators can:

- Monitor the banking command centre
- Manage customers
- View Customer 360 profiles
- Review account requests
- Review card requests
- Manage simulated balances
- Create financial transactions
- Reverse eligible transactions
- Manage verification
- Review risk cases
- Manage cards
- Review documents
- Manage notifications
- Handle Live Support
- View reports
- Review audit logs
- Understand banking workflows through the How It Works guide

---

## 🏦 Customer Dashboard

The customer overview is designed as a financial command centre rather than a simple balance screen.

It includes:

- Total balance
- Quick actions
- Financial insights
- Income vs expenses
- Savings growth
- Spending analytics
- Cash flow
- Recent activity
- Banking feature promotions
- Persistent Live Support access

All financial insights and analytics are designed to use actual application data rather than fabricated banking activity.
